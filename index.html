Supported formats: HH:MM:SS From [Name] to [Destination]: or YYYY-MM-DD HH:MM:SS From [Name] to [Destination]: on one line, message on the next (tab-indented). Both classic and new Zoom Save Chat exports work. The Time column carries the date: from the chat line when the export has one, otherwise from the paired attendee report. Spam windows, certificate timing and "Too Fast" de-duplication are evaluated per file.

Attendee matching: each savechat is paired with the attendee report whose names overlap most. Chat names are matched to User Name (Original Name); when several attendees share a name, the one who was in the session at the message time is chosen. Phone numbers are reduced to the last 10 digits (country code dropped). First join, last leave and total time in session come from the report's join/leave rows — overlapping rejoins are merged and the total is capped at the webinar's actual running time. Anything that cannot be matched gets #NA.
